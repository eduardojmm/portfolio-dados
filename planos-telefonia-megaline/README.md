# Comparação de Planos Pré-pagos da Megaline

Análise estatística para identificar qual dos dois planos pré-pagos da operadora Megaline, Surf ou Ultimate, gera mais receita, com base no consumo de 500 clientes ao longo de 2018.

**Principais etapas do projeto**

- **Preparação dos dados.** Ajuste de tipos de identificadores, datas e valores financeiros, e padronização das unidades de consumo de internet para alinhar com a cobrança de excedentes.
- **Perfil de consumo.** Comparação de chamadas, mensagens e uso de dados entre os dois planos, com análise da distribuição mensal.
- **Receita e testes de hipótese.** Cálculo da receita mensal por usuário e comparação estatística entre os grupos.

**Tecnologias**

Python, pandas, NumPy, SciPy, Matplotlib e Seaborn.
